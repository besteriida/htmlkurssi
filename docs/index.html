Pretty rivinvaihto

Tämä on testi siitä, miten pretty‑rivinvaihto käyttäytyy. Tarkoitus on nähdä, tasoittaako selain rivien loppuja ja välttääkö se rumia yksittäisiä sanoja riveillä. Testaan tällasia moderneja css vinkkejä mitä löysin modern-css.com.

Ei pretty rivinvaihto

Töherö, tämä on testi siitä, miten rivinvaihto käyttäytyy ilman pretty‑wrap ominaisuutta.

Näyttää toimivan ihan hyvin, hauska ominaisuus ja ei tarvi ite niin paljon miettiä et miten nyt rivittää. Tää on tosi hyvä jos toimii kans sit jos tekee jotaki bokseja tms. Tässä nyt esimerkki siitä miten tää rivittyy ilman tota prettyä eli laitetaas tähän jäätävä sana kuten epäjärjestelmällistymättömyydelläänsäkkäänköhän tai lentokonesuihkuturbiinimoottoriapumekaanikkoaliupseerioppilas
